# 0001: リポジトリ初期構成の引き継ぎ

## 実装者と目的

対象は GPT6-Luna［High］です。実行環境でモデルと推論設定を選択してください。このプロンプトを実行する際は、当該Planの実装者として作業してください。

## 読む資料

1. ルートの `AGENTS.md`
2. `docs/plans/0001-repository-structure.md`
3. `docs/specs/0001-repository-structure.md`
4. `README.md` と `docs/templates/` のテンプレート

## 作業範囲

初期構成は設計者が作成済みです。このプロンプトは別コンテキストでその構成を検証し、不足があれば補完するためのものです。既存の成果物が受け入れ条件を満たす場合は、変更や空コミットは不要です。

## 手順

1. 指示ファイルとGit状態を確認し、無関係な変更を保護する。
2. 設計書の配置・責務・命名と実際の構成を照合する。
3. Plan、設計書、プロンプト、テンプレートの不足や参照切れがあれば必要な文書を修正する。
4. 日本語、自動コミット、管理者への質問、実装者への引き継ぎの指示が `AGENTS.md` に含まれることを確認する。
5. ローカル参照と `git diff --check` を確認する。
6. 変更がある場合は今回のファイルのみ明示してステージし、日本語で自動コミットする。
7. 検証結果、変更内容、変更した場合のコミットID、未解決事項を日本語で報告する。

## 制約と完了条件

アプリケーションの実装や依存関係の追加は行わない。設計の重要な変更が必要なら理由を記録し、判断できない要件は管理者へ確認する。設計書の受け入れ条件を満たすことで完了とする。pushは依頼がある場合に限る。
