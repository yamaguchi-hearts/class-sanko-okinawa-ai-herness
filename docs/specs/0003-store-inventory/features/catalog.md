# 商品・カテゴリ管理

[設計索引](../README.md) / 対応: 原Plan §3.3、追加A-01

## 商品 F-PRODUCT

商品参照は両ロール、登録・編集・無効化はADMINのみ。商品編集DTOに現在庫や初期在庫の任意設定を含めない。0004の[R-OPENING](../../0004-demo-enhancements/features/opening-stock.md)適用後は、ADMINの商品新規登録でのみ初期在庫を設定でき、商品・OPENING履歴・監査を一つのトランザクションで保存する。0ならOPENING履歴を作らない。

| 項目 | 検証・動作 |
| --- | --- |
| SKU | 必須、trim後1〜64文字、ASCII英数字・`-`・`_`、大小文字を区別せず一意 |
| 商品名 | trim後1〜200文字、同名商品は許可 |
| カテゴリ | 任意。存在するカテゴリID。新規商品やカテゴリ変更時の新しい選択先は有効なもののみ |
| 単位 | trim後1〜16文字。初期提示「個」。換算しない |
| 最低在庫数 | 整数0〜数量上限、既定0 |
| メモ | 任意、最大2,000文字。空文字はnullに統一 |
| 状態 | 有効/無効。無効化後も表示・情報編集・履歴を保持 |

SKUの一意性は無効化済みも含む。変更時も再検証する。物理削除・SKU再利用による履歴の混同は認めない。カテゴリ無効化済みの商品は参照・編集でき、現在のカテゴリをそのまま維持することもできる。無効商品への在庫操作は拒否する。

## カテゴリ F-CATEGORY

ADMINが作成・名称変更・無効化する。名称はtrim後1〜100文字、正規化キーで大小文字を区別せず一意。使用中も物理削除しない。STAFFには参照用のID・名称・状態を返す。

カテゴリ無効化で所属商品を連鎖無効化しない。新規選択肢から外し、既存商品には「無効カテゴリ」と表示する。再有効化は原Planの必須操作ではないため初期版の独立機能に含めない。

## 永続化・失敗

入力検証、認可、業務変更と監査を一つのサービスで扱う。重複SKUは `DUPLICATE_SKU`、名称重複は `DUPLICATE_CATEGORY`、不存在は `NOT_FOUND`、新しい関連先が無効なら `INACTIVE_ENTITY` とする。フォームでエラーを該当項目へ示す。

## 受け入れ条件

F-PRODUCT-01: 必須、長さ、SKU大小文字・空白・無効化済み重複、編集後重複をMainとDBで検証する。

F-PRODUCT-02: STAFFが直接IPCで登録/編集/無効化を呼んでも拒否され、商品編集で現在庫を書き換えられない。

F-CATEGORY-01: 無効カテゴリの商品は参照・編集でき、新規選択は拒否され、商品・履歴が連鎖削除されない。
