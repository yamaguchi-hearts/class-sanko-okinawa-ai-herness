# 商品CSV出力

[設計索引](../README.md) / 対応: 原Plan §3.6

## 要求 F-CSV

ADMIN/STAFFが商品一覧をUTF-8 BOM付きCSVへ出力できる。インポートは初期版の対象外。現在の一覧条件とソートを引き継いで、ページ内だけでなく条件に一致する全件を一貫した読取スナップショットから出力する。

列は `SKU,商品名,カテゴリ,現在庫,最低在庫数,単位,状態,メモ` の順とし、先頭に日本語ヘッダーを置く。無効商品を含めるかは一覧の状態フィルタに従う。日時列を追加する場合は別途契約に記録する。

## ファイルと安全化

Mainで保存ダイアログを開き、既定拡張子を.csvとする。Rendererは検索条件だけを指定し、パスを任意指定しない。キャンセルは正常終了。書込みは一時ファイルから完成させ、失敗時は利用者の既存ファイルを壊さない。

カンマ、CR/LF、ダブルクォートを含むセルは二重引用符で囲み、内部引用符を二重化する。改行はCRLF。文字列セルについて先頭の空白・タブ・改行を除いた先頭が `=`, `+`, `-`, `@` の場合、または制御文字から始まる場合は元セルの先頭へアポストロフィを付ける。DBの元データは変更しない。数値列は検証済みの非負整数から生成する。

出力件数、条件、結果を監査し、秘密・全ファイル内容は保存しない。大量データはMainのUIを長時間停止させない。監査記録の部分失敗は監査設計に従って明示する。

## 受け入れ条件

F-CSV-01: BOM、列順、カンマ/引用符/改行、日本語、空メモ、式の先頭・先行空白/タブの安全化を単体テストする。

F-CSV-02: 複数ページの条件一致全件を出力し、キャンセル・権限・ファイル書込み失敗・監査を隔離ディレクトリで検証する。

F-CSV-03: WindowsのExcelで日本語と文字列セルが意図どおり表示されることを手動確認し、使用版を記録する。
