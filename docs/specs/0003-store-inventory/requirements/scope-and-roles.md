# 適用範囲・権限

[設計索引](../README.md) / 対応: 原Plan §1–3、§13、追加A-01

## 要求 R-SCOPE

- Windows 10/11 x64、1店舗・1台のPCで複数担当者が交代利用する日本語デスクトップアプリ。
- TypeScript、React、Electron、Vite、SQLite。DBはアプリのuserData領域へ永続保存し、終了・更新で消さない。
- 初回セットアップ、個人別アカウント、ログイン、認可、商品・在庫・履歴、CSV出力、手動バックアップと復元、配布ビルドを初期版に含む。
- セットアップ後の通常業務はオフラインで利用可能。ネットワークサービスに認証・保存・ライセンス検証を依存させない。
- ADMIN向けの明示的なオフライン管理者復旧ツールも初期版に含む。

## 権限の定義元

| 操作 | 未認証 | STAFF | ADMIN |
| --- | --- | --- | --- |
| セットアップ要否・初期管理者作成 | 条件付き可 | 不可 | 不可 |
| ログイン・再設定コード検証 | 可 | セッションとは別の認証経路 | 同左 |
| ロック解除 | ロック中の本人のみ | 本人のみ | 本人のみ |
| 自分のパスワード変更・ログアウト | 制限状態の契約に従う | 可 | 可 |
| ダッシュボード・商品・カテゴリ参照 | 不可 | 可 | 可 |
| 商品登録・編集・無効化 | 不可 | 不可 | 可 |
| カテゴリ作成・名称変更・無効化 | 不可 | 不可 | 可 |
| 入庫・出庫・棚卸調整 | 不可 | 可 | 可 |
| 在庫履歴参照・CSV商品出力 | 不可 | 可 | 可 |
| ユーザー管理・再設定コード発行 | 不可 | 不可 | 可 |
| 設定画面・設定変更・DB保存先表示 | 不可 | 不可 | 可 |
| 手動バックアップ・復元 | 不可 | 不可 | 可 |
| アプリ監査ログ参照画面 | 初期版には設けない | 同左 | 同左 |

セットアップはDBが未セットアップの場合に限る。通常画面用の店舗名と表示情報は、認証後のセッション表示契約に含める。STAFFに設定API全体を開放しない。再設定中・ロック中は業務APIを拒否する。

## 対象外

店舗・端末間同期、クラウド、POS、売上・価格・粗利、仕入先・発注、専用バーコード連携、ロット・期限・シリアル、複数単位換算、小数在庫、CSVインポート、帳票、細分化したロール、自動バックアップ・自動転送、多言語・テーマ切替。

## 受け入れ条件

R-SCOPE-01: ネット接続なしでセットアップ後のログインから在庫更新・履歴・バックアップまで動作する。

R-SCOPE-02: 上表をMainの認可テストに使用し、STAFFによる商品更新・管理機能呼び出しがUIとIPCの両方で拒否される。

R-SCOPE-03: 再起動・更新で商品と在庫が維持され、セッションのみ破棄される。
