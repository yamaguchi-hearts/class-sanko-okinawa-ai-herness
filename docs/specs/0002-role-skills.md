# 0002: 役割別Skill設計

## 参照・状態

- Plan: [0002-role-skills.md](../plans/0002-role-skills.md)
- 引き継ぎプロンプト: [0002-role-skills.md](../prompts/0002-role-skills.md)
- 状態: Skill作成済み

## 目的と範囲

設計から実装への役割を明確にし、別コンテキスト・別リポジトリでも再利用できる2つのSkillを作る。今回は依頼に従いSkill自体も作成・配置する。アプリケーションの実装は対象外。

## 構成・責務

| 配布原本 | 責務 |
| --- | --- |
| `.agents/skills/software-designer/SKILL.md` | Planの記録、設計書作成、自己完結した実装プロンプトの作成 |
| `.agents/skills/software-implementer/SKILL.md` | 引き継ぎ資料に基づく実装、検証、確定した設計変更の記録 |
| `AGENTS.md` | リポジトリ内での役割選択と共通規約 |

両Skillに名前と適用範囲を示すYAML frontmatterを設ける。各Skillは単独で使えるものとし、このリポジトリや他方のSkillのインストールに依存させない。UIメタデータや実行スクリプトは必要がないため追加しない。

設計書とプロンプトの標準配置・命名、日本語での作業、自動コミット、重要な不明点への質問を継承する。実装者のモデル選択は実行環境で行い、Skill自体はモデルを変更しない。自動選択は既定の有効状態を維持する。

## 配置と更新

管理者の追加指示に従い、2つのSkillをリポジトリ内の `.agents/skills/` に置いてGitで管理する。従来の `skills/` から移動し、参照も更新する。ユーザー共通のSkillsフォルダーへの配置・同期は通常の更新対象に含めない。前回配置したユーザー側のコピーは今回削除しない。

## 受け入れ条件・検証

- 2つのSkillが独立したフォルダーに存在する。
- `skill-creator` の `quick_validate.py` が両Skillに対して成功する。
- 説明文で設計と実装の適用範囲が分かれ、元の作業方針が保持されている。
- 両Skillが `.agents/skills/` に存在し、旧 `skills/` に重複を残さない。
- 文書のローカル参照と `git diff --check` を確認する。
- 今回の配置変更を日本語でコミットする。

Gitの作成者情報が不足する場合は管理者に確認し、コミット成功と誤って報告しない。今回の設計に未決事項はない。
